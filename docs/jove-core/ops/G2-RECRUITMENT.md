# G2 Pilot 招募操作包（20–30 例）

目标：20–30 个真实知情同意案例，覆盖 6 类数字任务（social content / account config / content publication / form & document / time-sensitive digital state / cross-evidence consistency），每个案例 2 名独立盲评。

## 招募对象

- 有可用的研究/测试账号、愿意做低风险数字任务并提交证据的人；
- 优先：AI2Human 现有运营商、agent 社区成员、高校参与者；
- 排除：无法提供真实可验证账号动作、或任务与隐私边界冲突的人。

## 招募文案（可直接发）

### 中文

> 📋 参与 JOVE-Core 研究 pilot（AI2Human 出品）
>
> 我们在做一项数字证据验证的研究：你完成一个低风险数字任务（发帖 / 配置账号 / 提交表单 / 状态核验等），提交结构化证据，我们评估验证系统能否可靠识别缺陷。任务小额补偿、可随时退出、原始证据不公开。
>
> 时间约 10–20 分钟。感兴趣私信我，或先看参与说明。

### English

> 📋 Join the JOVE-Core pilot study (by AI2Human)
>
> We study digital-evidence verification: complete a low-risk digital task (post / account config / form submission / state check), submit structured evidence, and we evaluate whether a verification system reliably detects defects. Small compensation, opt-out anytime, raw evidence stays private.
>
> ~10–20 minutes. DM me or read the info sheet first.

## 渠道

- AI2Human 平台运营商群（最高转化）
- X / Telegram agent 社区
- 高校 / 研究者个人网络
- 每个渠道记录来源，用于招募偏差说明（不强求均衡，但要在论文里如实报告）

## 流程要点

1. 先发参与说明（`pilot/participant-information.md`），口头 + 书面知情同意；
2. 用 `register-consent.mjs` 登记 consent 元数据（见 CONSENT-FORM.md）；
3. 每个案例严格走 `pilot/EXECUTION_RUNBOOK.zh.md` 的 10 步流程；
4. manifest 状态：planned → captured → validated，不跳步。

## 补偿

- 按完成的有效评分/案例计，不按"与系统一致"计；
- 具体金额由作者按当地合规确定，此处不预设。
