# JOVE-Core 知情同意书模板

与 `pilot/participant-information.md` 配套使用。此模板是提交给参与者的书面同意文本；登记用 `scripts/register-consent.mjs`。

---

**JOVE-Core 研究知情同意书**

研究名称：Proof-Carrying Agent Actions（数字证据验证）
研究单位：AI2Human（原型系统）

**我理解并同意：**

1. 我自愿参与一项低风险数字任务研究。我会使用自己拥有或专门用于研究的账号完成任务，不提交任何密码、私密消息、资金余额、政府证件、生物信息、私人联系方式或无关第三方数据。
2. 研究记录会保存任务文本、策略规则、证据哈希与数量、验证器观测、时间/成本元数据和决策回执。**原始证据不自动进入公开数据集**，保留在访问受控的产品存储中。
3. 我可以在提交前随时退出。退出不会影响我已完成的参与补偿（除非同意书另有规定）。
4. 我的参与记录以脱敏研究 ID（如 `pilot-XX`）标识，不使用钱包、邮箱或社交账号作为文件名。
5. 我的任务结果（包括被拒绝或要求补充证据）会被如实用于研究，可能以隐私裁剪后的形式出现在论文或公开工件中。
6. 数据保留期限：`[保留期限]`。到期后按研究隐私策略删除或匿名化。
7. 联系人：`[研究者联系方式]`。我可以随时就数据使用提出疑问或撤回同意。

**登记命令：**

```bash
node docs/jove-core/scripts/register-consent.mjs \
  --case-id=jove_core_0001 \
  --consent-at="<ISO 时间>" \
  --retention="<YYYY-MM-DD>" \
  --participant-reference="pilot-XX"
```

红线：**不得把历史生产数据当作默认 consent**；consent 必须逐案例、逐版本记录。

## 产品内采集（主要路径，已实现）

平台创建研究任务时，用户勾选同意框后，任务记录写入：

```json
{
  "campaign": {
    "researchConsent": {
      "version": "jove-core-consent-v1",
      "consentedAt": "<ISO 时间>",
      "retention": "2027-08-16"
    }
  }
}
```

`export-live-case.mjs` 导出时优先读取该字段（无 `--consent-at` 也能导出）；缺失 consent 的任务拒绝进入研究案例。此表格外的书面同意仅用于补充记录。
